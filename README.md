# Análisis exploratorio de patrones de sueño en estudiantes universitarios

## Descripción del proyecto

Este proyecto desarrolla un análisis exploratorio de datos sobre los patrones de sueño de estudiantes universitarios y su posible relación con los hábitos académicos y el estilo de vida.

A partir del conjunto de datos Student Sleep Patterns, se examinan variables como la duración y calidad del sueño, las horas de estudio, el tiempo frente a pantallas, el consumo de cafeína y la actividad física.

El análisis busca identificar patrones, explorar relaciones entre variables y comparar comportamientos mediante técnicas estadísticas y herramientas de visualización de datos.

## Instalación y ejecución

### Requisitos previos

- Python 3.10 o superior.
- Git.
- Visual Studio Code o Jupyter Notebook.

### 1. Clonar el repositorio

```bash
git clone https://github.com/AleZuHu/practica1_herramientas_ia_AleZuHu.git
```

### 2. Acceder al proyecto

```bash
cd practica1_herramientas_ia_AleZuHu
```

### 3. Crear un entorno virtual

En Windows:

```bash
python -m venv studentenv
```

### 4. Instalar las dependencias

```bash
pip install -r requirements.txt
```

### 5. Ejecutar el notebook

Abrir el archivo:

```text
notebooks/student_sleep_analysis.ipynb
```

Se puede ejecutar desde Visual Studio Code o mediante Jupyter Notebook.
